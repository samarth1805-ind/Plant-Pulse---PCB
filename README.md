# 🌱 Plant Pulse - Smart Plant Monitoring PCB

A custom **two-layer PCB** designed in **KiCad** for the **Plant Pulse** smart plant monitoring system.

This project integrates multiple sensors with an ESP32 microcontroller to monitor soil moisture and environmental conditions while efficiently managing power distribution. The PCB is designed to provide a compact, organized, and reliable hardware platform for an automated plant care system.

---

## 📖 Project Overview

Plant Pulse is an automated plant monitoring system that continuously observes the condition of multiple plants using dedicated sensors. The collected data is processed by an **ESP32** microcontroller, allowing the system to make informed decisions regarding plant health and maintenance.

This repository contains the custom PCB design created in **KiCad**, including the schematic, PCB layout, and 3D visualization.

---

## ✨ Features

- 🌿 Supports multiple soil moisture sensors
- 🌡️ Atmospheric sensor interface
- ⚡ ESP32-based controller
- 🔋 LiPo battery powered
- ⏱️ Power Timer for efficient power management
- 🛠️ Custom two-layer PCB
- 📐 Designed using KiCad
- 🎨 3D PCB visualization

---

## 🔧 Components Used

| Component | Purpose |
|-----------|---------|
| ESP32 | Main microcontroller |
| Soil Moisture Sensors | Monitor soil moisture of multiple plants |
| Atmospheric Sensor | Measures environmental conditions |
| Power Timer | Controls power distribution |
| LiPo Battery | Portable power source |
| Resistors | Signal conditioning and pull-up/pull-down connections |
| Pin Headers | External sensor connections |
